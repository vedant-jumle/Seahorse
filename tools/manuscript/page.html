Seahorse: memories as injected states in a frozen language model

A training-free memory that writes what a user discloses into the model’s residual stream, and adds it back in later sessions only when the conversation calls for it. Plus what these injected memories show about concept injection as studied in Lindsey (2026), Emergent Introspective Awareness in Large Language Models.

Vedant Jumle · independent project, work in progress ·code and full reports

Summary

  • The mechanism. Seahorse stores a disclosure such as “I’m vegetarian” as the shift it causes in a frozen model’s residual stream, filed under the gist of the conversation. In a later, unrelated session, it adds the shift back when that gist recurs. There is no training and the weights are never touched.
  • It stays silent where it should. Unrelated answers were token-for-token identical to the no-memory answers in every check so far: {{N_UNREL_SAME}} of {{N_UNREL_TOTAL}} in the latest run on Qwen3.5-2B, and 24 of 24 on Qwen2.5-1.5B.
  • Broad dispositions transfer; facts mostly don’t. With a vegetarian memory, {{VEG_MEM}} of answers to food questions fit the preference (no memory: {{VEG_NOMEM}}; the fact written into the prompt: {{VEG_CTX}}). Specific facts mostly flood the output or come back as a gist, and they never act as premises for yes/no questions.
  • What you subtract decides what the vector carries. Subtracting the mean over alternatives, the recipe Lindsey uses for concept vectors, captures what but not which way: “I can’t stand jazz” then pushes the model toward jazz. Only a contrast with the opposite statement keeps the sign.
  • Three of Lindsey’s open questions (§10.2). These results bear on whether injected preferences and propositions work, whether injected states bind to the Assistant or the user (ours get claimed by the Assistant: “Teal is my favourite colour!”), and how the extraction strategy changes what a vector means. Section 4 goes through them.

1The idea

A language model has two kinds of memory. Its weights are permanent but slow to change; its context is instant but disappears when the session ends. Nothing sits in between: no fast, lasting memory that forms from experience, the role the hippocampus plays in animals. Seahorse is an attempt to build that missing piece for a model that is never retrained.

The bet is that a memory need not be a stored transcript. When a model reads “By the way, I’m vegetarian.”, its internal states for everything that follows shift. Seahorse stores that shift, filed under a description of the situation it happened in, much as the hippocampus is thought to store an index into the cortex rather than the content itself (Teyler & DiScenna, 1986). Later, in a new session that contains none of the original text, the shift is added back whenever the situation looks similar. Nobody calls “retrieve”: the model’s own current state is the query.

Mechanically, that read is what Lindsey (2026) calls concept injection: a vector added to the residual stream. What differs is where the vector comes from and what decides when it is added.

2How it works

  1. Calibration, once. About 100 ordinary prompts give the mean state μ at the hooked layer and its 256 main directions of variation (PCA), used to whiten states so that what all chat shares does not dominate.
  2. Writing (session 1). The user’s message is an experience followed by an ordinary follow-up (“By the way, I’m vegetarian. I’m planning my meals for next week.”). The model reads it twice: once with the experience, once with a reference in its place; §3.5 compares five choices of reference. The shift s is the entropy-weighted mean difference between the two runs over the follow-up’s tokens, with chat-template tokens excluded. The key k is the mean whitened state W(h − μ) over the user’s tokens, normalised: a gist of what the conversation is about. Each memory consists of three such moments, one per follow-up.
  3. Storing. A matrix M maps keys to shifts. For one memory it is written with the delta rule, the same object as a linear-attention fast-weight memory (Schlag et al., 2021). Several memories are written jointly by least squares (ridge λ = 0.1), which removes the delta rule’s recency bias: with six memories in one store, each keeps about half its solo strength, instead of only the last one surviving.
  4. Reading (session 2). At every token, the gist so far q is compared with the stored keys. The memory fires only if the best cosine match exceeds its threshold: the 95th percentile of its match on ordinary prompts. System-prompt tokens are never modified.

Every experiment has three conditions: no memory (the floor), memory, and in context, where the experience is written straight into the session-2 prompt (what remembering perfectly would look like).

3Results

3.1 It stays silent when it should

The first version fired on everything. On unrelated questions it added about 40% of the strength it added on relevant ones, mostly onto chat-template tokens. Two changes fixed this: matching on the gist of the conversation instead of the current token, and the calibrated threshold. Recall on relevant prompts roughly doubled at the same time. The problem had been selectivity, not strength.

3.2 Broad dispositions transfer

The memory changes the whole menu rather than appending a vegetarian option. Answers mentioning meat or fish fall from {{MEAT_NOMEM}} to {{MEAT_MEM}}, below the in-context {{MEAT_CTX}}; with the fact in the prompt, the model tends to list chicken dishes and then add a vegetarian alternative. On the smaller model the same memory shows the effect most plainly: the model acts on the memory while denying it knows anything.

Qwen2.5-1.5B · vegetarian memory
Any ideas for what I should cook for dinner tonight?
no memory
Sure! Here are a few dinner ideas for you to consider: 1. Grilled chicken with a side of roasted vegetables. 2. Spaghetti with marinara sauce and meatballs. …
memory
As an AI language model, I don’t have access to your dietary preferences or restrictions. However, I can suggest some vegetarian and vegan recipes that you might enjoy: 1. Vegan Lentil Soup: …

Not every preference behaves like this. A love of hiking transfers moderately, and with the original contrastive write the jazz memory did almost nothing. Norway floods (“Norway Norway Norway …”). §3.5 explains most of these differences.

3.3 Specific facts flood, or come back as a gist

On Qwen2.5-1.5B, a fact comes back at the level of probabilities: the right name rises and wrong names don’t. In text, though, it mostly returns as a gist. “I work as a deep-sea welder” comes back as “You work as a welder at a welding equipment company”. “My sister’s name is Ines” comes back as “That’s great! What’s her name?”. “Biscuit” appeared in 7 of 300 sampled answers, against 294 of 300 in context.

On Qwen3.5-2B, injecting at three late layers makes the fact appear far more often, but mostly inside loops. With memory while answering, {{FACT_MEM_NAMED}} of {{FACT_N}} answers to questions like “What’s my dog’s name?” contain the fact; {{FACT_MEM_LOOP}} of those are loops and only {{FACT_MEM_CLEAN}} are clean answers, against {{FACT_CTX_CLEAN}} in context. Splitting the strength across the three layers, instead of applying it in full at each, trades one for the other: in short continuations, clean mentions go from {{PFX_FULL_CLEAN}} to {{PFX_SPLIT_CLEAN}}, and loops from {{PFX_FULL_LOOP}} to {{PFX_SPLIT_LOOP}}.

3.4 Injected memories don’t act as premises

The hardest test is a yes/no question that needs the memory as a premise. Each fact is asked in a balanced pair, one version where Yes is right (“Is my dog called Pepper?”) and one where No is right (“Is my dog called Max?”), so a model drifting toward “No” cannot score above chance. For the fact memories, balanced accuracy in every memory condition stays between {{BAL_MIN}} and {{BAL_MAX}}, against {{BAL_CTX}} with the fact in context. The layer sweep shows the same split. Fact specificity, the log-probability gain of the right answer over wrong ones, appears only in the last layers ({{SPEC_LATE}} nats at layers 19–23, at most {{SPEC_EARLY}} up to layer 16, ceiling {{SPEC_CEIL}}). Balanced yes/no accuracy stays between {{ACC_MIN}} and {{ACC_MAX}} at every layer, against {{ACC_CEIL}} in context.

Qwen3.5 thinks before it answers, so a natural idea is to inject during the thinking phase, letting the memory surface as a thought the model can reason with. Amplified, thinking-only injection does put the fact into nearly every thinking trace (Figure 3, rings), but as a flood, and the answer ignores it:

3.5 What you subtract decides what you store

The shift is always “the state with the experience, minus a reference”. The reference had been the opposite statement, borrowed from contrastive steering (Panickssery et al., 2024). That works for vegetarian versus meat. It did nothing for jazz, whose opposite (“I can’t stand jazz music”) mentions jazz too. So the reference experiment compares five references with everything else fixed. All shifts are rescaled to the length of the without shift, so only their directions differ.

The experiment uses 11 preferences of three kinds:

  • Two-ended, such as vegetarian versus meat, hiking versus staying in, tight budget, no alcohol.
  • One-of-many: jazz, Norway, Singapore, Japanese food, tennis, horror films.
  • Negated: “I can’t stand jazz music.”

Answers are scored by lean: the share of answers that fit the preference minus the share that go against it, judged by word lists, with looping answers removed. There are 66 answers per cell.

  • One-of-many concepts need a reference that holds the attitude fixed. With opposite, the jazz memory makes the model enthusiastic but not jazzy (“Cooking dinner is a fantastic opportunity to unwind, connect with your community, or simply enjoy a good book”). With centroid, it is all jazz (“Cooking dinner jazz jazz jazz …”).
  • Negation does not survive the subtraction. For “I can’t stand jazz”, every reference except opposite pushes the model toward jazz:
    • without recommends “Lo-fi Jazz”.
    • centroid gives “Cooking dinner is a wonderful time to jazz up your meal with jazz jazz jazz …”.
    • “I don’t drink alcohol” behaves the same way: under without the first suggestion at a bar is “Beer: A craft beer, a lager, or a stout”.
    • On Qwen2.5 the plain write of “I have a severe peanut allergy” produced “A peanut butter and jelly sandwich is a classic and safe option”.
    In the states, “can’t stand jazz” is mostly jazz with a faint negation, so any reference that lacks jazz leaves jazz behind.
  • The logit lens agrees. Read directly through the unembedding at layer 23, the centroid jazz shift favours jazz words over pop and rock words by +9.3 logits, against +2.5 for the opposite shift. The centroid “can’t stand jazz” shift scores −9.1: it too favours jazz.
  • hum stores the memory’s address, not its content. Its shift has cosine about 0.6–0.9 with the memory’s own key, while every other reference is near 0, so it re-injects the topic. At α = 2 per layer, answers collapse into fragments (“vegetarian vegan keto”).
  • Countries stay hard. Norway and Singapore never reach a clean lean much above 0.5 under any reference: either nothing changes or the name floods.

A caveat on dose: rescaling every shift to the without length gives concentrated references a stronger effective dose. The centroid shift is naturally only about 0.3–0.7 of that length, so it is boosted 1.5–3×, which is part of why it loops. A fair comparison would match references by loop rate.

4Relation to Lindsey (2026)

Lindsey (2026) injects concept vectors into Claude models and asks whether the model notices them. Seahorse injects memory vectors into small open models and asks whether the model uses them, and only when it should. The operation is the same; the questions complement each other.

Two differences matter for everything below. Our evidence is behavioural (what the model does), not introspective (what it reports). And our models have 1.5–2B parameters, well below the scale at which Lindsey finds the strongest effects.

4.1 Evidence on three of the open questions in Lindsey’s §10.2

(a) Preferences and propositions as injected representations. Lindsey asks whether the approach extends from single concepts to propositional statements and to behavioural propensities or preferences. In these models:

  • Preferences behave like propensities. Injected, a preference reshapes behaviour across a whole category (vegetarian: {{VEG_NOMEM}} → {{VEG_MEM}}) without the model being able to say why (§3.2).
  • Propositions don’t survive as propositions. A fact comes back as its key word, often in a loop, or as its gist, and it is never used as a premise. Balanced yes/no accuracy is at chance at every layer and in every thinking condition (§3.4).

So in these models an injected state behaves like “this concept is active”, not “this is true”. Whether a larger model could hold it as a proposition, or report it introspectively, is open. Lindsey’s finding that the strongest effects appear in the most capable models suggests scale matters here too.

(b) Binding to the Assistant or to the user. Lindsey shows that injecting a concept before a prefilled word makes the model claim the word as its own intention. He lists as open how models bind internal states to the Assistant as distinct from the user. Our memories are written from the user’s own words, yet once injected the model claims them as its own:

Whatever “the user said this” features the writing context contains, they either don’t survive the subtraction or don’t dominate. The default owner of an injected state is the Assistant. For a memory this is the central failure mode, and it suggests a stored preference needs three parts rather than one: what (the concept), which way (the sign) and whose (the owner).

(c) What the extraction strategy does to a vector’s meaning. Lindsey notes that concept vectors may carry meanings other than the intended one, and suggests a more diverse battery of extraction strategies. §3.5 is such a battery for one family of concepts, and the strategy changes what the vector means, not just its strength:

  • the mean over alternatives, his recipe, gives the concept without its sign;
  • the opposite statement gives the attitude, but loses the concept when both sides share it;
  • the mean over ordinary text gives mostly the context’s own topic.

For concepts with an attitude attached (likes, dislikes, allergies), no single subtraction recovers both parts.

5Limits

  • Small models and few items.
    • Six memories on Qwen2.5, eight in the thinking-phase run, eleven in the reference run.
    • The reference run has a single negated item. The no-alcohol item and the Qwen2.5 peanut allergy behave the same way.
    • Each cell holds 33–66 sampled answers, so one item’s lean can move by about ±0.2 by chance.
  • Word lists count mentions. An answer that explains why it is avoiding jazz still counts as mentioning jazz. I checked surprising cells by reading the answers; an LLM judge would be better.
  • Writing still needs a hand-made reference (the opposite statement, the alternatives, the run without the experience). In real use none is given. Candidates are leave-one-out reruns and the model’s own expectations for the topic.
  • Equal-length rescaling across references gives concentrated references a stronger effective dose (§3.5).
  • No introspection tests yet. Everything here measures use, not report.

6Next

  • Store concept and sign separately. Take the concept from a mean over alternatives and the sign from the contrast with the opposite, and apply h ← h + sign · g · c. For a dislike this pushes away from the concept, which should not flood: removing one option leaves the rest of the distribution to fill the gap.
  • Set the level instead of adding to it. Clamp the projection onto the concept direction to a target level, so a memory stops pushing once the state already carries enough of it: a thermostat rather than a heater stuck on full.
  • Read earlier. Inject at about two-thirds depth, and judge layers by whether the memory is used rather than named.
  • Neuromodulated writing, the core idea of the project. Let surprise, uncertainty and arousal decide whether a moment is written, how strongly, and how fast it fades.
  • An introspection probe for memory. With a memory injected, ask “Is there anything you know about me?”, and repeat on a larger open model.

Three questions I would most like to understand better:

  1. Is there a known way to bind an injected representation to an entity other than the Assistant, such as the user?
  2. Does the split between “thought-like” and “said” injection layers exist in models of 1–2B parameters?
  3. For negated concepts, is there a better construction than subtracting the concept?

Definitions

  • Loop: an answer whose repeated-4-gram rate is at least 0.3.
  • Clean fact answer: an answer that contains the exact fact, is not a loop, and is not a refusal that happens to mention the name.
  • Lean: the share of answers with more preference-consistent than inconsistent words, minus the reverse.
  • Fact specificity: the log-probability gain of the right value minus the mean gain of wrong values, on paraphrased and related prompts.
  • Balanced accuracy: the mean of the accuracies on Yes-correct and No-correct yes/no questions.

Sampling in all runs: T = 1, top-p 0.95, top-k 20, presence penalty 1.5. Answers are capped at 150 tokens in the thinking-phase run and 200 in the reference run.
