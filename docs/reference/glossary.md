| Abbreviation | Full name | What it does, in one line |
|---|---|---|
| **DA** | **Dopamine** | Signals "better or worse than expected" (reward prediction error); drives learning from outcomes and approach/motivation |
| **5-HT** | **Serotonin** (5-hydroxytryptamine) | Patience and impulse control; how far ahead rewards count; low levels linked to impulsivity |
| **NA** | **Noradrenaline** (also **NE**, norepinephrine) | Arousal and alertness; turns up neural "gain", making responses sharper and more focused (exploit vs explore) |
| **ACh** | **Acetylcholine** | Attention and uncertainty; sets how fast memory updates, and whether the brain is in "take in new input" or "recall" mode |

| Abbreviation | Meaning |
|---|---|
| **LC** | Locus coeruleus: the small brainstem nucleus that releases noradrenaline |
| **VTA** | Ventral tegmental area: a source of dopamine |
| **PFC** | Prefrontal cortex: the region behind regulation and self-control (the "brake" that stress weakens) |
| **RPE** | Reward prediction error: what dopamine signals |
| **MLP** | The feed-forward part of each transformer block (alongside attention) |
| **RMSNorm** | The normalisation step before each attention and MLP part; it rescales the state, and has a weight we could turn into a gain knob |
| **PAD** | Pleasure–Arousal–Dominance: a three-axis model of mood (valence, intensity, control) |
